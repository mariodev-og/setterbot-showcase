# Recursos visuales / Visual assets

- **`arquitectura.svg`** — diagrama del flujo del sistema / system flow diagram.
- **`panel.png`** — recreación de la interfaz real del panel, hecha a partir de
  las plantillas del sistema y poblada con **datos de ejemplo**. Reproduce la
  estructura, las columnas y los estados reales de la interfaz; los valores no
  corresponden a cuentas, propiedades ni personas reales.

---

# 🇬🇧 English

- **`arquitectura.svg`** — system flow diagram.
- **`panel.png`** — a recreation of the real panel interface, built from the
  system's own templates and populated with **example data**. It reproduces the
  interface's real structure, columns and states; the values don't correspond to
  real accounts, listings or people.
