## Capturas del panel

Las capturas de pantalla del panel usan **datos tomados de producción,
adaptados para la muestra de funcionalidad**: los valores reales de clientes se
reemplazaron por datos de ejemplo, conservando la estructura y el
comportamiento reales de la interfaz. No representan cuentas ni personas reales.
